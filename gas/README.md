# 耳つぼ「シールを外す日」お知らせメール セットアップ（約10分・1回だけ）

Customer Card から予約を受け取り、当日の朝9時台に **あなたのGmail** からお客様へ自動送信します。
パスワードをアプリやClaudeに入力する必要はありません（Googleの画面で、あなた自身が許可します）。

## 手順
1. https://script.google.com を開き、「新しいプロジェクト」を作る（名前例：耳つぼお知らせ）
2. 最初から入っているコードを全部消して、このフォルダの `reminder.gs` の中身を貼り付け、保存
3. `setToken` 関数の「ここを自分の合言葉に書き換える」を、推測されにくい合言葉に書き換える
4. 上の関数選択で `setToken` を選んで「実行」→ Googleの許可画面が出るので、自分のアカウントで許可
5. 関数選択で `setupTrigger` を選んで「実行」（毎朝9時に自動で動く設定）
6. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（合言葉で守られます）
7. 表示された「ウェブアプリのURL」をコピー
8. Customer Card の右上「データ」→「耳つぼ お知らせメール設定」に、URLと合言葉を貼って保存

## 仕組みと注意
- 予約は、あなたのGoogleドライブに自動作成される「耳つぼお知らせメール予約」スプレッドシートに溜まります。送信済みかどうかもそこで確認できます。
- 送られる情報は、お客様のお名前・メールアドレス・送信日・メール本文だけです（写真・お悩みは送りません）。
- 無料のGmailは1日100通までです。
- 送信日から3日以上過ぎた未送信の予約は、古い案内を送らないよう「expired」になります。
- お客様のメールアドレスの登録には、お客様の同意が必要です（アプリの同意チェックで記録します）。
